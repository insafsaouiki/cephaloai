\# CephaloAI



Détection automatique de 19 landmarks céphalométriques sur radiographies.



\## Installation

pip install -r requirements.txt



\## Lancer l'application

streamlit run app/app.py



\## Données et modèles

Le jeu de données cepha400 et les modèles entraînés (.pth) ne sont pas

inclus dans le dépôt. Télécharger cepha400 depuis \[lien] et placer les

images dans data/raw/cepha400/.
